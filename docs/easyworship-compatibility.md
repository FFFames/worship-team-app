# EasyWorship compatibility

Reference behavior comes from the [EasyWorship feature catalog](https://easyworship.com/software/features), the [EasyWorship 7 user guide](https://supportresources.easyworship.com/EasyWorship7Manual.pdf), and the [profile transfer documentation](https://support.easyworship.com/support/solutions/articles/24000043114-transfer-easyworship-profile). The web app keeps its chord and playlist workflows alongside presentation features.
